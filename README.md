# 🐾 AR Cute Walking Cat (ฉบับอัปเดตแก้ปัญหาการแสดงผล)

โปรเจกต์ Web AR แมวน้อยเดินดุ๊กดิ๊ก ปรับความเร็วได้ และเปลี่ยนสีได้ 3 สี

### 📁 ไฟล์ในโฟลเดอร์นี้:
1. `index.html` - โค้ด Web AR ฉบับปรับปรุงใหม่ (ใช้ Direct A-Frame Primitives แสดงผล 100% ทันทีที่เจอ Marker)
2. `marker.png` - ภาพ Hiro Marker ของแท้จาก Official AR.js Repository
3. `README.md` - คำแนะนำการใช้งาน

### 🚀 วิธีเอาขึ้น GitHub:
1. อัปโหลดทั้ง `index.html` และ `marker.png` เข้าแทนที่ไฟล์เดิมบน GitHub
2. ไปที่การตั้งค่า **GitHub Pages** (Settings > Pages)
3. เปิดหน้าเว็บผ่านมือถือ แล้วส่องกล้องไปที่รูป `marker.png` บนจอคอมฯ หรือพิมพ์ใส่กระดาษ
4. น้องแมวจะโผล่ขึ้นมาเดินทันที พร้อมกดปุ่มเร่งความเร็ว และเปลี่ยนสีได้ทันทีครับ!
