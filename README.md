# 🐾 Cute AR Walking Cat (แมวน้อย AR วิ่งได้)

โปรเจกต์ Web AR น้องแมวน่ารัก เดินดุ๊กดิ๊ก เมื่อส่องกล้องไปที่ Marker (Hiro Marker)
สามารถนำไปอัปโหลดขึ้น **GitHub Pages** แล้วเปิดเล่นบนมือถือได้ทันที!

## ✨ ฟีเจอร์เด่น
1. **เมื่อส่อง Marker**: น้องแมว 3D สุดน่ารักจะปรากฏขึ้นมาพร้อมแอนิเมชันขาก้าวเดินและหางส่ายดุ๊กดิ๊ก
2. **ปุ่มปรับความเร็ว (Speed Control)**:
   - เดินชิล (1x)
   - เดินเร็ว (2x)
   - วิ่งสับ! (4x)
3. **ปุ่มเปลี่ยนสีแมว (3 สี)**:
   - 🐱 สีส้ม (Orange Tabby)
   - 🐈‍⬛ สีดำ (Black Cat)
   - ⚪ สีขาว (White Kitty)
4. **ระบบเสียง Meow สังเคราะห์อัตโนมัติ**: กดเปลี่ยนสีหรือเปลี่ยนความเร็วจะมีเสียงร้องเหมียวน่ารักทันที ไม่ต้องโหลดไฟล์ mp3 ภายนอก
5. **ปุ่ม "ดู Marker 📷" บนหน้าจอ**: สามารถเปิดภาพ Marker ขึ้นมาบนหน้าจอได้เลยหากไม่ได้พิมพ์ใส่กระดาษ

---

## 🚀 วิธีนำขึ้น GitHub Pages เพื่อเปิดบนมือถือ

1. สร้าง Repository ใหม่บน GitHub เช่น `ar-cute-cat`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `marker.png`, `README.md`) ขึ้นบน repo (กิ่ง `main`)
3. ไปที่แท็บ **Settings** ของ Repository -> เมนู **Pages** ทางซ้ายมือ
4. ตรงหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที GitHub จะให้ URL เช่น:
   `https://<ชื่อยูสเซอร์>.github.io/<ชื่อrepo>/`
6. ใช้มือถือเปิด URL ดังกล่าว (รองรับทั้ง iOS Safari และ Android Chrome) แล้วกด **Allow / อนุญาตให้เข้าถึงกล้อง**

## 📷 วิธีสแกนเล่น
1. เปิดไฟล์ `marker.png` บนจอคอมพิวเตอร์ แท็บเล็ต หรือมือถืออีกเครื่อง (หรือกดปุ่ม "ดู Marker 📷" บนหน้าเว็บ)
2. ใช้มือถือที่เปิดเว็บส่องไปที่ภาพ Marker
3. น้องแมวจะกระโดดออกมาเดินทันที! ลองกดเปลี่ยนสีและกดเพิ่มความเร็วดูได้เลยครับ
